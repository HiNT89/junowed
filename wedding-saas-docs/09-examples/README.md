# Illustrative Code Examples

These snippets show contract shape and database structure. They are not a complete application. In particular, payment verification, transaction locking, full domain routing, media processing and production auth are intentionally not implemented here.

- `models.py`: baseline SQLAlchemy models.
- `template-manifest.json`: sample manifest.
- `template-adapter.ts`: pure data mapping.
- `example-wedding.json`: example canonical data.
