## Audit questions
- Which files contain names, dates, locations, photos, music, guest content?
- Does template require server APIs or only browser JS?
- Can it render in an iframe with isolated CSS?
- Does it depend on third-party fonts/scripts/CDNs?
- Is commercial reuse allowed by licenses?
- Does it render with fake customer data and no hardcoded constants?

## Prioritization
Choose one simple HTML template, one representative React template and one complex Next.js template as integration pilots. Estimate each migration only after audit.
